Azeroth DB browser extension

Search the WoW Forever database on Azeroth DB without leaving the page you are on. Type wow, a space and the name of an item, talent, spell, recipe, quest, dungeon or zone in the address bar; suggestions come from Azeroth DB's own search index. Or select a name on any page and look it up from the right-click menu.

Get the extension

Setup and permission details are in the public repository; downloads are on its latest release.
